# Sources and scope

Artwork: original editable path drawings for spacelibre, generated directly
from locally authored Bezier coordinates. No third-party illustrations, raster
tracing, filters, network asset retrieval or embedded images.

Registration metadata retained from Stellarium western sky culture:
https://github.com/Stellarium/stellarium-skycultures/tree/014fbb5e59233d133c22f9811af96b67d05a95c9/western
License CC-BY-SA-4.0. The new drawing frames are derived from actual HIP unit directions using an
equatorial north-up tangent projection, a 25% margin and a 4-degree minimum
half-angle. Old illustration pixel anchors are not used for the new drawings.
HIP directions remain unchanged. Artistic frames are not constellation boundaries.

Stellar directions: Olaf Frohn and d3-celestial contributors, BSD-3-Clause,
revision 7e720a3de062059d4c5400a379146a601d9010e0. Formula:
(cos(dec)cos(ra), cos(dec)sin(ra), sin(dec)), J2000 equatorial radians.

Pinned source URLs, hashes and per-drawing output hashes: provenance.json.
IAU standard naming applies to constellations; the IAU does not prescribe
these fictional illustrations. Illustrations do not redefine sky boundaries.
