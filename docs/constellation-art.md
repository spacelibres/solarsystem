# 西方星座原创 SVG 与天球定位

2026-10-20 用户要求停止收集互联网素材，改为直接生成原创 SVG。
此前 WebP 描摹与第三方素材候选方案均已取消。

## 素材与维护

85 幅独立原创 SVG 采用透明背景、白色细轮廓和内部细节，覆盖 88 个 IAU
星座名称。船底、船尾、船帆共用南船图案；蛇夫图案包含巨蛇。图案通过
AI 辅助直接编写贝塞尔路径，无位图、滤镜、字体、图片描摹或网络素材依赖。

源坐标在 `tools/constellation-art/original-batch-{a,b,c}.py`；修改路径后运行
`python tools/constellation-art/build.py`，重建 SVG、索引及 SHA-256 清单。
生成脚本只读本地源文件，无第三方 Python 依赖。常规 dev/build 不调用生成器。

原创图案以 MIT 许可发布。恒星配准元数据继续保留 Stellarium 的 CC-BY-SA
及 d3-celestial 的 BSD 许可和固定版本；不会把已有数据标为原创。

## 天文学约定

沿用 IAU 88 星座名称和三字母缩写、ICRS/J2000 方向。IAU 规定天区、名称，
没有唯一官方人物动物图案。插画不是天区边界，也不宣称人体关节必须与某颗星
重合。历史 B1875 边界不能直接当作 J2000 坐标；本功能不新增边界。

每幅图案绑定三个 HIP 恒星单位方向；以三颗星的平均方向为中心，用 J2000
天球东、北轴构建切平面，留出 25% 余量，再求 512x512 图框内的像素锚点。
最小半角为 4°，避免小图案消失；不复用旧插画的倾斜像素坐标。恒星方向
保持不变，艺术绘图框不等同 IAU 天区边界。共享 `registration.js` 构建配准平面后
归一化到天球。NASA 星表的老人星和织女星已与 J2000 赤经赤纬核对，不再
额外重复旋转黄赤交角。艺术轮廓可调整，但不得更改恒星方向来迎合插图。

## 实际渲染

`vector-geometry.js` 使用 SVGLoader 解析原生路径、细分曲线、生成填充或
描边三角形并投射到天球，只返回数值数组。Eyes 恢复版 Three 和 Explorer
npm Three 分别建立自己的 GPU 对象，两种 Three 对象不混用。

当前目录图案全部 `renderMode: vector`，不会先转为 512px 贴图。顶点着色器
只使用相机旋转，图案随观察方向变化，不随太阳系距离缩放。图案图层与连线、
标签分别切换，默认关闭；淡入淡出且深度不写入，避免覆盖前景天体。

加载限制并发，支持关开重试、取消及销毁；每幅几何生成之间让出主线程。
图案加载成功后清理对应错误状态。源码说明和来源清单位于
`eyes/shell/constellation-art/`，没有新增 NASA 素材镜像。

## 验证边界

自动测试检查 88 名称覆盖、锚点单位长度、独立原生路径、透明背景、许可与
摘要、三点配准、加载取消/重试和数值几何。视觉质量与图案姿态仍需实际浏览器
检查，测试通过本身不能证明艺术效果。
