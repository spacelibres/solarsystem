# Eyes 轨道、参考体与星空修正 · v0.2.37

本次修正针对用户指出的基本展示错误。v0.2.36 的对象接入和测试不等于画面符合 Eyes；尤其是错误的标签白点、统一轨道配色和简化星空，不能算对齐。

## 根因与实现

### 参考体和真实位置

原目录已有八行星 `parentId=sun`、月球 `parentId=earth`，求值器按世界轴将父相对平移相加。但是近景的可见集合只保留太阳和选中对象，计算需要的地球被隐藏；总览也排除了月球。新导航保留太阳、八行星、月球和选中对象祖先。天体近景保留天然卫星，系统视图再包含该系统的航天器等对象。

旧标签避让可移动180像素，CSS白点跟着文字移动，看起来像天体脱离轨道。现在实体白点是独立DOM标记，固定在真实世界位置的相机投影。文字只在附近避让；过密名称隐藏，标记不移动。隐藏的文字不表示对象被删掉，缩放或选择对象可显示其名称。

`relativeEphemeris` 从同一快照减去当前父级位置与速度，显示距离、速度和J2000坐标。月球的距离不是日心距离；缺少父级状态时不生成假读数。页面明确显示围绕天体并可跳转父系统。

### 轨道线

真实应用的最终配色来自 `eyes/src/engine/managers/TrailManager.js`，覆盖注册表 `trail.color`。不能直接用工厂颜色，更不能用统一蓝灰或黄色替代：

| 对象 | RGB（显示编码） | 常态透明度 |
| --- | --- | --- |
| Mercury | #9768AC | 0.75 |
| Venus | #B07919 | 0.75 |
| Earth | #0099CC | 0.75 |
| Mars | #9A4E19 | 0.75 |
| Jupiter | #DA8B72 | 0.75 |
| Saturn | #D5C187 | 0.75 |
| Uranus | #68CCDA | 0.75 |
| Neptune | #708CE3 | 0.75 |
| Moon / 默认对象 | #FFFFFF | 0.35 |

独立配置保留浮点原值，Three颜色空间转换不会把显示编码误当线性值再变亮。官方 `Line2` 使用1.2 CSS像素常态线宽，避免系统忽略原生WebGL线宽。源值通过执行隔离后的实际TrailManager构造器对照，不靠截图猜颜色。

`OrbitLineComponent._updateMesh` 用当前父相对位置和速度以及GM重建瞬时轨道；旧版取最近粗采样记录画线，会与插值后的当前天体错开。新实现由角动量和偏心率向量重建椭圆，每度采样，并插入当前天体位置。线的父级平移与实体相同：行星以太阳为焦点，月球以地球为焦点，不乘父级自转。

近景按 `VisibleInterval.DefaultVisibleFar` 的标准化半径阈值0.02、fadeBlur0.5渐隐轨道。源公式与独立函数有直接对照测试，防止月球放大后自身轨道穿过月面。瞬时密切轨道仍不等于完整长期历史轨迹。

### 星空和星座

`StarfieldComponent._loadStars` 使用Pioneer的wxyz四元数。旧共享解析器直接把wxyz传给Three的xyzw构造器，误作约180度旋转；现按23.439度黄赤交角正确转换。旧测试也把错误旋转当作预期，已改为分量与角度断言。

原来只加载stars.0/1，统一点大小且丢失绝对星等。独立渲染器现在加载galaxies.0及stars.0–5七层，保留真实方向、颜色、距离和绝对星等。亮度沿用源光通量公式，点大小、透明度及五次方圆形衰减沿用源公式；Float64计算光通量避免远距平方在GPU溢出。投影改写为官方Three的-Z前向相机，不复制Pioneer的+Y投影语句。

星座来自同一NASA `stars/constellations.bin`：名称、4颜色字节、星点数、float32三元组、连线数与字节索引，按真实顺序读取并检查截断/非法索引。轴转换和黄赤交角与星表一致。88个星座、673段连线；标签采用源等距归一化包围盒中心。星座默认关闭，与Eyes启动图层一致，可通过“星座连线与名称”打开；恒星默认开启。

透明星空、星座线位于远深度并参与深度测试，实体遮住其后方的星空；DOM星座名称也检查实体球体遮挡。源星座颜色为RGBA(.35,.7,1,.5)。当前星座线仍用原生LineSegments，未宣称已达到源2像素线宽的跨GPU一致性。

## 实测与边界

实时资源核对见本机 `artifacts/solar-reference-live.log`：

- ET845440000及ET845526400：Sun、八行星与Moon全部ready；八行星父级为Sun，Moon父级为Earth，所有非根对象的位置在一天后改变。
- 首时刻地日距离149145187.24km，月地距离404842.73km、相对速度0.967966km/s；第二时刻月地距离404571.45km。
- 七层均HTTP200，共43878点；星座文件HTTP200，10952字节，88个星座、673段连线。资源仅运行时引用，未镜像媒体库。
- 浏览器核对总览配色、固定物理标记、星空/星座开关、月球Earth参考体与可展开的星历读数，以及近景实体遮挡；截图在 `artifacts/`。

正常的日期无覆盖与网络/格式失败分开显示。`snapshot.unavailablePaths` 只标记具有精确不可用区间的no-data，诊断仍保留原错误详情；不能用反复重试修复已经结束的任务日期。发现TESS当前片段 `sc_tess/earth/orb/201.dyn` 有相同时间的冲突记录，仍明确报无效数据，本次没有擅自去重或隐去。

仍未宣称整个应用逐像素相同：完整大气/遮影/后处理、特殊控制器、所有任务机构、全部故事和工具沿原计划继续。上述轨道颜色原值和基础层级已经有直接源码及运行数据证据，不能以其他未完成功能为由继续使用错误替代。
