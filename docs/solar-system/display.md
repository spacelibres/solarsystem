# 对象与展示链路

## 数据、分类与按需场景

`npm run solar:catalog` 从可编辑 Eyes 注册源码静态提取清单，`npm run solar:catalog:check` 检查再现性。844个原始注册中，独立日心视图用太阳静态根替换银河上下文，目录显示842项。原始分组包括8行星、454天然卫星、221航天器、106小行星和14彗星，分组可能交叉。738项注册提供模型描述。这些是源码登记数量，不是所有对象、所有日期和所有行为均通过运行验收。

`scene-catalog.ts` 将描述转换为自己的具名 TypeScript 配置；不执行旧模块或回调。保留父级阶段、候选数据路径、源顺序控制器和模型变换。相同父级的多次飞越按路径参考体筛选候选，再由真实二进制覆盖决定哪一个可用，不能把控制器索引当阶段索引。

源运行时通过排序插入父级条目。NEAR的原表未排序，转换时按相同规则排序。Lucy有重复起点：原规则在精确边界取第一条，之后取最后一条；转换保留边界条目并在紧接的可表示ET加入后续条目，避免把重复起点误判为整个应用无法初始化。

运行时 `activeIds` / `setActive` 只请求所需系统、选择对象及其当前父级和姿态依赖。目录外其他对象可以被搜索，但不会因为目录很大就同时下载738个模型。实体没有可用位置时不显示假坐标；模型姿态未知会显示明确说明。

## 总览、系统、近景

- `overview`：太阳、八大行星和月球，按真实距离/半径显示，完整外太阳系取景。远处的物体依靠投影标签标出真实位置；不擅自放大行星几何。
- `system`：选中天体及其源分组/直接子级，按该天体系统半径取景。
- `body`：近距离选中对象，同时保留太阳系和父级上下文，保持真实物理尺寸与相机相对坐标；环行星的取景包含外环；模型加载后按脱离父级的真实包围体重新取景，包含长杆和偏心模型，避免把声明半径当完整模型尺寸而裁切。

相机采用标准Three的-Z前向、Z上方向，原始世界坐标不变。世界位置先减焦点再写入GPU。模型未知姿态时使用中性观察变换并注明未知，不保留上一时刻的姿态冒充当前结果。视场角取景根据窄边计算，避免宽屏裁切。

标签是可点击的屏幕投影，屏幕后方及视口外不显示。实体白点固定在真实投影位置；文字只在附近避让，过密名称隐藏，不再携带白点偏移180像素。系统导航和标签/轨道开关在窄屏布局仍保留，真实触控设备需要另行验收。

## 模型与材质资源

真实模型通过官方Three GLTFLoader、DRACOLoader、KTX2Loader和MeshoptDecoder读取。依赖解码器使用构建发布的固定revision路径。模型默认米转千米缩放0.001；源明确scale则覆盖该值；局部旋转按源顺序左乘；局部平移不被局部旋转/缩放误乘。详见 [模型资源](models.md)。

聚焦模型总是请求；其他模型在屏幕尺寸足以分辨时才请求，亚像素目标先用名称标示。最多两个物理解码任务，每个租约独立拥有GPU资源。切换视图释放模型、几何、材质和纹理；迟到结果不得挂入新视图。

球体继续使用原始六面坐标与颜色图，不将face0拉伸成球。太阳使用自己的六面图及原光晕。环半径来自`Unidentified695.js`：土星74270.580913–140478.924731km、天王星26840–103000km、海王星40900–62964km；环图U沿半径归一化，V=0。上下表面分别使用源纹理。高级遮影/散射没有因此完成。

## 轨道与轨迹

行星及月球的椭圆轨道由当前父相对位置、速度和GM重建，每度采样并插入当前天体位置，避免最近粗星历要素画线与当前插值位置错位。其他`orb`轨迹保留与求值器相同的重心质量因子；默认无body选择时不额外缩放。它是瞬时密切椭圆，不伪称为完整历史轨迹。

`pos/lin`及非椭圆轨道线按独立求值器在实际窗口内采样，截断到已读取覆盖，不在未知日期补直线/圆环。轨迹以其阶段父级的当前世界位置平移，不额外乘父级姿态。切阶段、丢失覆盖或更换视图时不继续把旧轨迹当作当前轨迹显示。轨迹请求与数据运行时分开拥有小预算repository，并受取消和视图generation保护。
